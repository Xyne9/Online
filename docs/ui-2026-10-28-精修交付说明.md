# 2026-10-28 界面精修交付

本轮属于现有产品的整理。用户已确认上一轮六项诊断，并授权按该方向精修。
北极星：让用户先看清当前任务和结果，再按需查看执行细节。白底科技蓝、判题语义色与接口契约沿用。

## 改动

1. 登录：独立未登录布局，去掉演示身份和通知；表单支持 Enter 提交、错误反馈、保留输入与原有回跳。
2. 判分链：补齐单格结果色，首个失败点与其余失败分开强调；默认演示态为 8 通过、2 未通过，与摘要相符。真实态仍读取服务端 caseDetails。
3. 工作台：AI 栏在主视口和较窄桌面分别为 376／352px；阶段标签完整横排，协同细节按需展开。
4. 测试点详情：Enter／空格可钉住或取消；缺少对应详情时不复用第 3 点示例。浮层宽度独立于格子，不在较窄桌面折碎。
5. 监考：切屏橙、断线红，卡片、演示事件、详情与分布保持等级一致；原有筛选、排序与操作沿用。
6. 学情：通过图例与绿格一致，按实际出现的 WA／TLE 等结果显示图例；去掉重复总数、样本行和趋势底部重复 AC 数字。
7. 走查修正：教学回复正文不再混入 Router／Tool／模型通道信息；“执行过程”按需展开，降级／护栏／中断通知仍可见。展开判分链后焦点进入首个失败点，收起后回到展开按钮。

## 设计取舍

- 用户确认六项诊断，无否定项；具体栏宽和表单位置是 Agent 的实现判断。
- `prototype/design-notes.md` 追加本轮决定，没有新建设计系统或改全局 token。
- 结果定位和异常卡的侧线保留，用于表达对应关系和告警等级。文件大小提示不引入无关拆分重构。
- 不做门户重塑、其他业务页移动端改版、后端改动或模型行为调整。
- 沿用现有动效，将失败格抖动收敛为淡入；没有增加业务步骤。
