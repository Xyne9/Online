## 三、本轮修复的真缺陷（都来自实际跑验收时暴露的问题）

### 3.1 【阻断级】两个服务因缺 `loadbalancer` 起不来

`oj-teaching-service` 与 `oj-judge-service` 都 `@EnableFeignClients` 并按服务名调用，
但 pom 里只有 `spring-cloud-starter-openfeign`（openfeign 在 common-api 里是 compile 传递），
缺 `spring-cloud-starter-loadbalancer`。启动期直接：

```
IllegalStateException: No Feign Client for loadBalancing defined.
Did you forget to include spring-cloud-starter-loadbalancer?
```

→ 8081/8083 端口根本不通，第五步全部验收无法开始。两处 pom 已补依赖并注明原因。

### 3.2 【阻断级】教师题库首屏 500 —— Java 三元表达式自动拆箱 NPE

```java
// 错：Integer 与 int 常量混用三元，结果类型被定成 int，q.getState() 为 null 时拆箱炸
Integer state = teacherOrAbove ? q.getState() : ProblemDict.STATE_PUBLISHED;
```

教师带 `state=null` 查题库 → `NullPointerException`（日志 traceId `c7f1fea33b7b`）。
改为 `if/else` 显式赋值。**这个坑任何教师第一次打开题库都会踩到**。

### 3.3 【阻断级】考试编辑器全选覆盖后草稿保存成空串

`readEditor()` 按 `.cl`（行号行）逐行解析。但用户 **Ctrl+A 全选再输入/粘贴** 时，
contenteditable 会把整块内容塌成一个纯文本节点，`.cl` 全部消失 → 读回空串 →
草稿保存空、判题拿不到代码。实测 `readEditor()` 返回 `""`。

修法：无 `.cl` 时回退 `innerText`；并在失焦时用 `normalizeEditor()` 重建行号结构
（编辑中不动 DOM，避免顶飞光标）。

### 3.4 【体验级】监考事件姓名重复 + 秒数泄露浮点

- 后端 `message` 已是完整句子（"张三切屏达到3次，已标红"），前端模板又固定渲染 `{who} {what}`
  → 显示成"张三 张三切屏达到3次"。改为 message 已以学生姓名开头时 `who` 留空，**模板一行未动**。
- `awaySeconds` 是 `performance.now()` 差值，直接拼进中文 → "离开3.1042000000011174秒"。
  后端统一格式化：整数秒不带 `.0`，否则保留一位小数。

### 3.5 【可复现性级】本地模型查重打分乱跳

同一对代码连问 5 次，`qwen2.5-coder:7b` 给出的相似度是 **[0.5, 0.9, 0.8, 0.8, 0.95]**——
同一份输入三个风险等级，查重结论不可复现，验收随机红。

根因是**没有给评分标尺**。补上 0.90/0.75/0.40 三档分界后，再问 6 次稳定在 **[0.90, 0.98]**。
同时查重是判定类任务（不是创作），`DynamicAiModelFactory` 新增 `streaming(channel, temperature)` 重载，
查重链路固定 `temperature=0`，讲题链路仍用通道配置的 0.3。

### 已知环境约束

1. **登录限流**：`oj:rate:login:{ip}` 存在 1 分钟窗口上限（实测 12 次）。短时间反复重跑验收会撞 `429 登录尝试过于频繁`。等 60 秒或 `redis-cli DEL oj:rate:login:127.0.0.1`。
2. **单会话 token**：同一账号重复登录会顶掉旧 token，所以两套验收**不能并行**。
3. **验收脚本不清理自己造的数据**：`verify-day12.py` 每跑一次会新增 1 道验收题 + 2 个活动。想在演示前恢复干净数据，按 `logs/day12-backend/report.json` 里的 `fixtures` 删即可。
