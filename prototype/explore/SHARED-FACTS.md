## 一、题目（题面内容，逐字使用）

- 编号：`#1024`
- 标题：**最大子段和**
- 难度：中等 ｜ 标签：动态规划、前缀和
- 限制：时限 1000 ms（Java / Python ×2）· 内存 256 MB · 隐藏测试点 10 组

题面正文：

> 给定一个长度为 n 的整数序列 a₁…aₙ，请找出其中一段连续子序列，使得它的元素之和最大。子序列至少要包含一个元素。

输入格式：第一行一个整数 n（1 ≤ n ≤ 10⁵）。第二行 n 个整数，|aᵢ| ≤ 10⁴。
输出格式：一个整数，表示最大子段和。

示例 1

```
输入
6
-2 11 -4 13 -5 -2
输出
20
```

说明：取子段 `[11, -4, 13]`，和为 20。

示例 2

```
输入
3
-1 -2 -3
输出
-1
```

提示：全部元素为负数时，答案也是负数。

## 二、学生代码（C++，逐字使用）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int dp = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        dp = max(dp + x, x);
        ans = max(ans, dp);
    }
    cout << ans << endl;
    return 0;
}
```

第 7 行 `int dp = 0, ans = 0;` 是缺陷所在（ans 初值取 0，全负数组时输出 0）。
