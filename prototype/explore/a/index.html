#1024

最大子段和

中等

动态规划 · 前缀和

给定一个长度为 n 的整数序列 a₁…aₙ，请找出其中一段连续子序列，使得它的元素之和最大。子序列至少要包含一个元素。

输入格式 第一行一个整数 n（1 ≤ n ≤ 10⁵）。第二行 n 个整数，|aᵢ| ≤ 10⁴。
输出格式 一个整数，表示最大子段和。
示例 1
输入
6
-2 11 -4 13 -5 -2
输出
20

说明：取子段 [11, -4, 13]，和为 20。

示例 2
输入
3
-1 -2 -3
输出
-1

提示：全部元素为负数时，答案也是负数。
