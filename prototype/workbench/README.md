# 学生做题工作台 · A + C 融合稿

A 方向（判分链）作主框架，把 C 方向（协同面板）的模型切换与智能体流水线折中收进右侧 AI 抽屉。
入口：`index.html`（直接双击或用任意静态服务器打开）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构，Alpine 写在属性上 |
| `styles.css` | 全部样式，设计变量集中在 `:root` |
| `app.js` | 唯一的 Alpine 组件 `workbench()`，状态与演示时序 |
| `vendor/alpine.min.js` | 本地 Alpine，无 CDN 依赖 |
| `VUE-MIGRATION.md` | 迁移到 Vue 3 + Element Plus 的完整对照（12 节 + 附录） |
| `_shots/` | 各状态截图；`final10/` 是 10 个状态的基准图 |
| `_notes/` | 迁移文档的取证材料（EP 官方源码摘录、样式事实表），非交付物 |

## 怎么走一遍

地址参数直接进入任意状态（不复制页面）：

```
index.html                  WA 80/100 默认态
index.html?state=hint       行内批注展开
index.html?state=think      思考过程（流水线）展开
index.html?state=judging    判题中，链带逐格点亮
index.html?state=ac         AC 100/100，第 4 阶段解锁
index.html?state=locked     点已锁的第 4 阶段
index.html?state=closed     AI 抽屉收起
index.html?state=cloud      云端模型
index.html?state=stage1     阶段① 读题拆解
index.html?state=stage2     阶段② 编码引导
```

真实操作路径：**提交 → 判题中（10 格逐个点亮）→ WA 落定（第 3 格抖动放大）→ 点行内批注「全负时 ans 停在 0」→ 批注条展开 →「改成 −10⁹」→ 提交 → AC 100/100**。
另有：点右上角 `AI 助教` 开关或右侧 64px 窄轨上的按钮收起/展开抽屉；点思考条展开 Router → Tutor → Guardrail 三张卡；点模型分段控件在「本地极速 / 云端」间切换；在追问框输入后回车。`Esc` 依次关批注条、关抽屉。

## 设计要点

**判分链是主角。** 底部 10 格占满整行，失败的第 3 格宽 2.9 倍、高 70px、红底白字，上方带一个 12px 菱形指针，指向浮在上面的说明卡（输入 / 期望 / 实际）。这一格是整个页面唯一的高饱和红，其余全是冷白与浅蓝，视线第一眼必然落在它上面。

**AI 抽屉分三层。** 顶部是 C 方向的分段控件（本地极速 Qwen2.5-Coder 7B / 云端 DeepSeek），比 A 原来藏在底部的迷你切换直观；中间是回复正文；回复上方有一条可折叠的「已协同 3 个智能体 · 调用 getFailedTestCaseFeature · 护栏审查通过 ▾」，平时收着不打扰做题，展开就是 C 方向完整的 Router → Tutor → Guardrail 节点卡，带工具调用与生成进度。

**行内批注而不是浮层。** 错误说明直接长在第 8 行下面，和代码行一对一，读完能顺手点「改成 −10⁹」。

**题面与代码各自滚动。** 1280×800 下题面区装不下全部内容，所以 `.prob-body` 独立滚动，并在底部做 18px 渐隐，提示「下面还有」。判分说明与事实表钉在题面底部不随滚动走。

**阶段窄轨常驻最右。** 4 个 64px 窄条（读题拆解 / 编码引导 / 排错诊断 / AC 复盘），当前阶段蓝底，已完成打勾，第 4 阶段虚线锁住并在抽屉里给出解锁条件。

## 状态与交互覆盖

| 项 | 覆盖 |
| --- | --- |
| 默认 / 加载 / 空 / 错误 | 默认 WA；判题中（逐格点亮 + 脉冲）；AC；阶段未解锁 |
| hover / active / focus / disabled | 格子、批注胶囊、按钮、分段控件、阶段条、追问框；提交中按钮保持原宽并禁用 |
| 尺寸稳定性 | 状态切换只改颜色/边框/阴影，不改宽高；模型滑块用 `translateX` 位移 |
| 减弱动效 | `prefers-reduced-motion` 下关闭全部动画与过渡 |

## 校验结果

- 10 个状态 × 1440×900 全部出图，无控制台错误、无横向溢出、无加载失败图片。
- 1280×800 与 1920×1080 复核通过。
- 端到端链路实测走通：提交 → 判题中（10 格逐格点亮）→ WA 落定（第 3 格抖动）→ 点行内胶囊展开批注 → 点「改成 −10⁹」应用修正 → 重新提交 → AC 100/100 且阶段④解锁，全程无控制台错误。
- 对比度：判题中未判格 `#4E5C71` 于 `#F4F7FC` 上 5.9:1；锁定阶段标签改为 `#55637A` 后 4.6:1，均达标。
- 唯一保留的小字号是流水线工具卡里的元信息行（10.5px），属于次要信息，按规范可小一级。

## 已知取舍

- 演示数据写死在 `app.js`，没有接后端。
- 判题时序用 `setTimeout` 模拟（每格约 120ms），真实接入时换成 SSE 或轮询。
- 抽屉宽度固定 322px（≤1280px 时压到 296px，≤1080px 时 272px，并逐级隐藏主导航与倒计时）；未做移动端布局，这是桌面端工作台。
- 迁移到 Vue 3 + Element Plus 的完整对照见 `VUE-MIGRATION.md`（12 节 + 附录，含组件映射、主题定制、接口对接与踩坑清单）。
