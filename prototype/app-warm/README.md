# 智判 OJ · Warm Paper 全站版本

这是基于 `prototype/app/` 完整复制后制作的独立暖纸感视觉版本。旧版保持原样；本目录可单独预览，不会自动替换旧版入口。

## 设计方向

- 暖纸白外壳、淡藕粉 AI 辅导区、莓紫主动作、墨紫深色代码编辑器。
- 判题语义色仍保留 AC / WA / TLE / MLE / RE / CE 等含义，不用品牌色替代结果色。
- 共享颜色与语义变量集中在 `styles/tokens.css`；工作台特有的编辑器材质和分栏比例集中在 `styles/workbench.css`。
- 保留现有 HTML / Alpine.js / API / adapter / mock 双轨结构，避免将视觉探索与业务重构混在一起。

## 页面

门户与登录页，以及学生端 6 页、教师端 7 页、管理端 2 页均保留原来的文件名与相对导航关系：

- `index.html`、`login.html`
- 学生：`s-problems.html`、`s-workbench.html`、`s-assignments.html`、`s-submissions.html`、`s-analytics.html`、`s-exam.html`
- 教师：`t-dashboard.html`、`t-problems.html`、`t-problem-edit.html`、`t-assignments.html`、`t-analytics.html`、`t-monitor.html`、`t-plagiarism.html`
- 管理：`a-models.html`、`a-audit.html`

## 预览

在仓库根目录运行项目现有静态服务脚本时，需将服务根目录指向 `prototype/app-warm/`；或者用任意静态 HTTP 服务器托管本目录。做题工作台建议先用 `?mock=1` 查看离线模拟交互。

新的探索入口为 `prototype/explore/warm-paper.html`，它嵌入此版本的 `s-workbench.html?mock=1`。
